In the HERE SDK for Android Navigate, you don't need to convert distance to zoom level manually — the SDK provides MapMeasure.Kind.DISTANCE_IN_METERS directly:

✅ Official Way (Built-in)
kotlin
val distanceInMeters = 800.0  // e.g., 800 meters view
val mapMeasure = MapMeasure(MapMeasure.Kind.DISTANCE_IN_METERS, distanceInMeters)
camera.lookAt(targetCoordinates, mapMeasure)
Or with animation:

kotlin
camera.zoomTo(mapMeasure, Duration.ofSeconds(1))
Key Facts
Property    Value
Correct Kind    MapMeasure.Kind.DISTANCE_IN_METERS 
Zoom range    [0, 22] for dedicated zoom levels 
Current zoom    camera.getState().zoomLevel 
Current distance    camera.getState().measure (gives distance in meters) 
Your Manual Formula is NOT Needed
The snippet you mentioned (16 - log₂(d/500)) is custom math you don't need — just pass the distance directly:

kotlin
// ❌ Custom formula (not needed)
val zoomLevel = 16 - (log2(distanceMeters / 500))
camera.zoomTo(zoomLevel)

// ✅ Built-in (official)
camera.lookAt(target, MapMeasure(MapMeasure.Kind.DISTANCE_IN_METERS, distanceMeters))
The SDK automatically handles the distance→zoom conversion internally.
