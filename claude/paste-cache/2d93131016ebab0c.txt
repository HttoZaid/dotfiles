Based on the HERE SDK Android Navigate documentation, here's the correct API for getting distance-to-next-turn and maneuver information:

Correct API Properties
What You Need    Correct API Path
Distance to next maneuver    routeProgress.maneuverProgress[0].remainingDistanceInMeters 
Current/next maneuver    visualNavigator.getManeuver(nextManeuverProgress.maneuverIndex) 
Maneuver action    nextManeuver.action (e.g., ManeuverAction.TURN_LEFT) 
Maneuver text    eventText.text via EventTextListener (as you confirmed) 
Distance to destination    routeProgress.sectionProgress.last().remainingDistanceInMeters 
Key Code Pattern (Kotlin)
kotlin
visualNavigator.routeProgressListener = RouteProgressListener { routeProgress ->
    // Get next maneuver progress
    val nextManeuverProgress = routeProgress.maneuverProgress[0] ?: return@RouteProgressListener
    
    val remainingDistance = nextManeuverProgress.remainingDistanceInMeters  // ✅ Correct
    val maneuverIndex = nextManeuverProgress.maneuverIndex
    
    // Get the actual maneuver
    val nextManeuver = visualNavigator.getManeuver(maneuverIndex)
    val action = nextManeuver.action
    val roadName = nextManeuver.nextRoadTexts.names.getDefaultValue()
}
Important Notes
Maneuver objects must come from VisualNavigator/Navigator, NOT from Route — during navigation, maneuver.getText() from Route is empty

EventTextListener IS correct for maneuver text — it provides localized guidance strings like "Turn left onto Street X in 500 meters"

RouteProgress.maneuverProgress contains a list of ManeuverProgress for the next maneuver + following maneuvers

The API reference for HERE SDK Navigate v4.26.0.0 is available at the official docs.
