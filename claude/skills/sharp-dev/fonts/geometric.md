# Geometric / Modern Pairing

**Character:** Clean · Modern · Precise · Neutral
**Pairs best with:** Slate, Midnight, Chalk, Ocean palettes

## Fonts

```
Role       Font                Weights
──────────────────────────────────────────────────
Display    Plus Jakarta Sans   400, 500, 700, 800
Body/UI    Inter               400, 500
Mono       IBM Plex Mono       400, 500
```

## Google Fonts Import

```html

```

## CSS Variables

```css
--font-display: 'Plus Jakarta Sans', system-ui, sans-serif;
--font-sans:    'Inter', system-ui, sans-serif;
--font-mono:    'IBM Plex Mono', monospace;
```

## Usage Notes

Use Plus Jakarta Sans for display/headings only (it shines big).
Use Inter for all body text and UI — the most legible UI font available.
IBM Plex Mono is slightly warm for a mono font, avoiding the sterility of Courier.
Best for B2B SaaS, dashboards, developer tools.
