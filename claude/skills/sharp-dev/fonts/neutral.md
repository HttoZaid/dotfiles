# Neutral / Utility Pairing

**Character:** Clean · Versatile · Universal · No personality
**Pairs best with:** Any palette — true neutral
**Use when:** Product must not have visual personality (documentation, internal tools)

## Fonts

```
Role       Font          Weights
──────────────────────────────────────────────────
Display    Work Sans     600, 700, 800
Body/UI    Manrope       400, 500, 600
Mono       Roboto Mono   400, 500
```

## Google Fonts Import

```html
<link href="https://fonts.googleapis.com/css2?family=Work+Sans:wght@600;700;800&family=Manrope:wght@400;500;600&family=Roboto+Mono:wght@400;500&display=swap" rel="stylesheet">
```

## CSS Variables

```css
--font-display: 'Work Sans', system-ui, sans-serif;
--font-sans:    'Manrope', system-ui, sans-serif;
--font-mono:    'Roboto Mono', monospace;
```

## Usage Notes

Work Sans has just enough personality in the heavier weights to work as a display font.
Manrope is a highly legible grotesque — excellent for data-heavy interfaces.
This pairing is the "safe choice" that works with literally any palette.
Use for: internal tools, documentation, whitelabel products.
