# Slab Serif Pairing

**Character:** Sturdy · Technical · Grounded · Trustworthy
**Pairs best with:** Ocean, Moss, Midnight palettes

## Fonts

```
Role       Font               Weights
──────────────────────────────────────────────────
Display    Zilla Slab         300, 400, 600, 700
Body/UI    Lato               300, 400, 700
Mono       Source Code Pro    400, 500
```

## Google Fonts Import

```html
<link href="https://fonts.googleapis.com/css2?family=Zilla+Slab:wght@300;400;600;700&family=Lato:wght@300;400;700&family=Source+Code+Pro:wght@400;500&display=swap" rel="stylesheet">
```

## CSS Variables

```css
--font-display: 'Zilla Slab', Georgia, serif;
--font-sans:    'Lato', system-ui, sans-serif;
--font-mono:    'Source Code Pro', monospace;
```

## Usage Notes

Zilla Slab has excellent x-height — it works well at 18px+ for display
but also at body text sizes (15px). Very versatile.
Lato is one of the most neutral sans-serifs available.
Best for documentation sites, developer dashboards, finance tools.
