# Humanist Pairing

**Character:** Friendly · Quirky · Readable · Approachable
**Pairs best with:** Forest, Rose, Clay palettes

## Fonts

```
Role       Font          Weights
──────────────────────────────────────────────
Display    Fraunces      100, 400, 700, 900
Body/UI    Nunito        400, 500, 600
Mono       JetBrains Mono 400, 500
```

## CSS Variables

```css
--font-display: 'Fraunces', Georgia, serif;
--font-sans:    'Nunito', system-ui, sans-serif;
--font-mono:    'JetBrains Mono', monospace;
```

## Usage Notes

Fraunces is a variable optical-size serif — at small sizes it looks one way,
at large sizes it morphs. Use opsz=144 for big display titles, opsz=9 for captions.
Nunito has rounded terminals that match Fraunces's warmth.
Excellent for wellness, journaling, consumer apps.
