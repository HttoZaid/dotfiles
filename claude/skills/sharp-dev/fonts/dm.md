# DM Font Family (Default)

**Character:** Warm · Humanist · Readable · Professional
**Pairs best with:** Clay, Obsidian, Forest palettes

Display    DM Serif Display    DM+Serif+Display         400, 400i

Mono       DM Mono             DM+Mono                  400, 500

## CSS Variables

```css
--font-display: 'DM Serif Display', Georgia, serif;
--font-sans:    'DM Sans', system-ui, sans-serif;
--font-mono:    'DM Mono', 'Courier New', monospace;
```

## Usage Notes

DM Serif Display is ideal for large editorial headings (Display, Title 1).
It has warmth and personality without being decorative.
DM Sans is the cleanest humanist sans — excellent legibility at all sizes.
DM Mono is perfectly matched in weight with DM Sans so they sit well together.
