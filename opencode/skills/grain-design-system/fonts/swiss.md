# Swiss / Impact Pairing

**Character:** Bold · Confident · High-impact · Loud
**Pairs best with:** Ember, Chalk, Midnight palettes

## Fonts

```
Role       Font              Weights
──────────────────────────────────────────────────
Display    Bebas Neue        400 (only weight)
Body/UI    Helvetica Neue    400, 500  (system)
Mono       Courier New       400 (system)
```

## Google Fonts Import

```html
<link href="https://fonts.googleapis.com/css2?family=Bebas+Neue&display=swap" rel="stylesheet">
```

## CSS Variables

```css
--font-display: 'Bebas Neue', Impact, sans-serif;
--font-sans:    'Helvetica Neue', 'Arial', system-ui, sans-serif;
--font-mono:    'Courier New', monospace;
```

## Usage Notes

Bebas Neue is ALL CAPS only — only for display/hero text, never body.
Pairs with ultra-clean system sans for maximum contrast.
Use for: bold marketing pages, fitness apps, food, sports.
Never use Bebas below 24px — it becomes unreadable.
The all-system-font body stack makes this pairing load at zero cost.
