# Editorial Pairing

**Character:** Elegant · Refined · Literary · High-end
**Pairs best with:** Sand, Dusk, Rose palettes

## Fonts

```
Role       Font                  Weights
──────────────────────────────────────────────────
Display    Playfair Display      400, 500, 700
Body/UI    Source Sans 3         300, 400, 600
Mono       Fira Code             400, 500
```

## Google Fonts Import

```html
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,400;0,500;0,700;1,400&family=Source+Sans+3:wght@300;400;600&family=Fira+Code:wght@400;500&display=swap" rel="stylesheet">
```

## CSS Variables

```css
--font-display: 'Playfair Display', Georgia, serif;
--font-sans:    'Source Sans 3', system-ui, sans-serif;
--font-mono:    'Fira Code', 'Courier New', monospace;
```

## Usage Notes

Playfair Display is a high-contrast serif — best at 28px+ only.
Never use it below 20px, it loses legibility.
Source Sans 3 is extremely clean and works at any size.
Great for editorial blogs, luxury brands, portfolio sites.
