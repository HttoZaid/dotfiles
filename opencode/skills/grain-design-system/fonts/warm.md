# Warm Literary Pairing

**Character:** Warm · Intimate · Literary · Storytelling
**Pairs best with:** Rose, Sand, Clay palettes

## Fonts

```
Role       Font           Weights
──────────────────────────────────────────────────
Display    Crimson Pro    400, 400i, 600, 700
Body/UI    Karla          400, 500, 600
Mono       Space Mono     400, 700
```

## Google Fonts Import

```html
<link href="https://fonts.googleapis.com/css2?family=Crimson+Pro:ital,wght@0,400;0,600;0,700;1,400&family=Karla:wght@400;500;600&family=Space+Mono:wght@400;700&display=swap" rel="stylesheet">
```

## CSS Variables

```css
--font-display: 'Crimson Pro', Georgia, serif;
--font-sans:    'Karla', system-ui, sans-serif;
--font-mono:    'Space Mono', monospace;
```

## Usage Notes

Crimson Pro is one of the most refined web serifs — much better than Google's
earlier Crimson Text. Works beautifully at body text sizes too.
Karla is a slightly quirky sans that retains warmth.
Space Mono adds a retro typewriter feel to code/data elements.
Best for: personal blogs, journaling, wellness, storytelling apps.
